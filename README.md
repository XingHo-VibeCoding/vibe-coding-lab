# 随手笔记 NoteLab

一个自己用的极简笔记网页：**打开就能写，用 `#标签` 归类，能搜、能翻。**
不登录、不上云、不联网 —— 数据只存在自己这台电脑的浏览器里。

> Day 7 完成 MVP。技术路线见 `TECH_DESIGN.md`，功能与验收标准见 `PRD.md`。

---

## 一、怎么运行（运行说明存档）

本项目是纯静态网页，**两种打开方式，任选一种**。

### 方式 A：本地服务器（推荐，地址栏会是 localhost）

在项目文件夹里打开终端，执行：

```bash
cd C:/D/Projects/vibe-coding-lab
python -m http.server 8123 --bind 127.0.0.1
```

然后浏览器访问：

```
http://localhost:8123/
```

停止服务：在终端按 `Ctrl + C`。

> 本机 python 路径（如果 `python` 命令找不到）：
> `C:\Users\岚\.workbuddy\binaries\python\versions\3.13.12\python.exe`

### 方式 B：直接双击（最省事）

直接双击 `index.html` 用浏览器打开也能用，全部功能正常。
缺点：地址栏显示的是 `file:///...` 而不是 `localhost`。

### 浏览器要求

只保证 Chrome / Edge 桌面版最新版正常（PRD 第 5 节）。

## 二、怎么用（对照 PRD 的五个功能）

| 功能 | 怎么用 |
|---|---|
| **F1 写笔记** | 打开页面光标就在输入框里，直接打字；按 `Ctrl + Enter` 或点「保存」 |
| **F2 标签归类** | 正文里写 `#标签`（例如 `#想法`），保存后自动归类；点左侧标签可筛选，再点一次取消。标签区分大小写，一条最多 5 个 |
| **F3 关键词搜索** | 顶部搜索框输入即筛选，正文和标签都能搜到，命中的词会高亮 |
| **F4 随机回顾** | 点「翻一翻」，随机翻出一条旧笔记（笔记少于 3 条时会提示先多记几条） |
| **F5 本地保存** | 自动保存，关掉浏览器再打开笔记还在；不需要登录 |

### 数据流（一句话）

输入框 → `app.js` 拆标签组装笔记对象 → 存进 localStorage 的唯一位置（`loadNotes()` / `saveNotes()` 两个函数）
→ 打开页面时读回内存 → 渲染成列表 / 搜索 / 随机回顾。**全程不经过任何服务器。**

## 五、怎么改（约束，来自 TECH_DESIGN 第 7 节）

1. 不加任何第三方依赖、不用 npm、不用构建工具
2. 不发任何网络请求，断网必须完全可用
3. 不引 CDN 上的字体和图标
4. 存储读写只能写在 `loadNotes()` / `saveNotes()` 里，别处不许直接碰 localStorage
5. 单个文件超过 500 行就拆开
